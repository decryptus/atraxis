# Atraxis 1.0.11 — candidate, not yet published

Native `monit_docker` sources support three explicitly selected outbound authentication modes: Basic (the default), Bearer API tokens, and anonymous access for intentionally public read-only inventory. Existing Basic configurations remain valid. No credential fallback occurs after an authentication failure. Other adapters and inbound Atraxis authentication are unchanged; TLS and redirect restrictions remain in force.

For Monit-Docker 2.x SQLite authentication, use a private ASCII token file with the `status:read` scope and `auth_mode: bearer`. For a deliberately public source, use `auth_mode: none` and omit `credentials_file`. See the [source configuration guide](../source-configuration.md). Preserve source IDs, inventory grants and existing data when changing a source connection.
