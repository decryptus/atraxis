# Atraxis 1.0.8

The guided installer in Python package 1.0.8 and the Compose starter in tag
v1.0.8 both select the verified Linux amd64 image `decryptus/atraxis:1.0.7`.
Previously, the 1.0.7 wheel selected image 1.0.5 and its tagged starter
selected image 1.0.6. The pilot already runs image 1.0.7.

For guided installations, run `python -m pip install 'atraxis[textual,installer]==1.0.8'`.
For the Compose starter, check out `v1.0.8` and follow `docs/docker-compose.md`.
Both paths use the proxy configuration for per-client authentication limits.

Qualification reuses the 1.0.7 service and endurance evidence. The release
check compares the installed wheel payload with that baseline, allowing only
the tested installer image pin and package version. CI starts the guided stack
and verifies its running image identity and authenticated HTTPS readiness.
