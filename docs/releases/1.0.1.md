# Atraxis 1.0.1

Atraxis 1.0.1 makes the optional rule client installable directly from PyPI and
adds the first Linux amd64 Docker Hub distribution image.

- `atraxis[rules]` now pins `atropos-client[observations]==1.0.0`; a separate alpha
  client source installation is no longer needed. The engine remains independent.
- Compose and integration inputs use the matched Atropos engine/client 1.0.0.
- The Docker image includes Atraxis and the client, runs as UID/GID 10001, and
  initializes its persistent account directory with private `0700` permissions.
- Installation instructions, architecture diagrams and related-software guidance
  are included in the updated documentation.

See the [Docker guide](https://github.com/decryptus/atraxis/blob/v1.0.1/docs/docker-image.md), [remote client installation](https://github.com/decryptus/atraxis/blob/v1.0.1/docs/rule-remote.md)
and [support matrix](https://github.com/decryptus/atraxis/blob/v1.0.1/docs/v1.0.md). Source, wheel and Docker image availability are
separate publication steps. Pin available version tags or digests in deployments.

## Upgrade and scope

Atraxis Python runtime modules are unchanged from the original 1.0.0 qualification.
Atropos's stable engine/client functional modules match the previous inputs apart
from their version constants. The original 1.0.0 release archives remain unchanged.
No database/configuration conversion is introduced.

Fresh installation, native browser/service integration, container chains and
cold restoration are checked on the final source. The Docker tests additionally
exercise the published client, authentication, signal handling and account state
retained across container recreation. The original operational and four-hour
synthetic endurance evidence keeps its original scope; no new throughput,
external-recipient, high-availability or multi-architecture claim is made.

Back up state before replacing an installation. Saving/testing rules does not
activate them; activation does not dispatch actions. Workers and authorized
bindings remain explicit, and uncertain outcomes still require reconciliation.
