# Atraxis 1.0.0

First stable Atraxis package for the documented Linux amd64 / Python 3.11–3.12
reference configuration. It provides read-only inventory, authenticated
web/API/CLI/Textual interfaces, scoped account and inventory administration,
and explicit rule lifecycle operations through the independent Atropos client.

Direct `monit_docker` and `certlord` discover resources automatically and preserve
native fields, including certificate domains and fingerprints. Covenant and
Prometheus remain optional; their complete native routes use the observation
plugins named in the support guide. Generic Prometheus sources expose selected
numeric measurements.

The release closes the reference installation/recovery and integration gates:
coordinated cold restoration on a distinct host with current authority, audit,
TLS renewal and paused execution; and one explicitly authorized source-bound
HTTPS diagnostic through Auton with actual local firing/resolution receipt and
duplicate refusal. The recorded four-hour synthetic workload retains its original
SQLite/Redis scope. These checks do not qualify arbitrary remediation, external
mail/chat recipients, production capacity or high availability. Atropos remains
an independently versioned alpha dependency.

The runtime Python modules match the qualified RC build. The attached wheel and
source archive are the exact files from the successful installed-package CI,
not a later rebuild. `release-provenance.json` records the reviewed source tree,
required checks, bounded qualification manifest and archive hashes; `SHA256SUMS`
checks the attachments. Publication here does not publish to PyPI.

## Install

On Linux with the system libmagic library, download the attached wheel and use a
fresh Python 3.11 or 3.12 environment:

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install ./atraxis-1.0.0-py3-none-any.whl
atraxis --help
```

This installs the base package without starting services or authorizing actions.
Follow the [support and upgrade guide](https://github.com/decryptus/atraxis/blob/v1.0.0/docs/v1.0.md),
[setup](https://github.com/decryptus/atraxis/blob/v1.0.0/docs/setup.md) and
[Compose guide](https://github.com/decryptus/atraxis/blob/v1.0.0/docs/docker-compose.md)
for optional interfaces and matching services. Preserve backups and current
revocations; unsupported older formats are rejected without conversion/deletion.
