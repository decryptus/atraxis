# Atraxis 1.0.9

The service uses HTTPdis 0.7.1. Listeners use a default TCP backlog of 128. When upgrading a service that uses HTTP Basic authentication, replace legacy SHA-1 or DES htpasswd entries with supported hashes such as bcrypt before restarting.

The guided Compose installer still selects its previously qualified image. Use the versioned native package for the updated dependency until the new container image is qualified.

The [qualification manifest](1.0.9-qualification.json) identifies the prior operational evidence and its scope. The release workflow verifies the current candidate and its package artifacts.

The web service pins DWho 0.3.69 and Sonicprobe 0.3.65. See the [IPv6 ingress limits](../http-transport.md) before exposing a custom dual-stack proxy.
