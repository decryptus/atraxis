# Atraxis 1.0.10

The web service now requires Sonicprobe 0.3.66. Sonicprobe supplies missing `Date` and `Message-ID` headers for outgoing email while preserving caller-provided values. No product runtime Python files or storage formats change.

The guided Compose installer still selects its previously qualified image until the new container publication and digest are verified. Use the versioned native package for the updated dependency.

The [qualification manifest](1.0.10-qualification.json) identifies inherited operational evidence and its scope. Current package, integration, browser and image workflows are required for this candidate. No new endurance or external email delivery evidence is claimed.
